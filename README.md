# 스왑데이 개인정보처리방침

이 저장소는 '스왑데이' 앱의 개인정보처리방침 공개 페이지를 호스팅합니다.
GitHub Pages로 게시되며, Play 스토어 등록 정보의 개인정보처리방침 URL로 사용됩니다.

- 페이지: https://parkin02026.github.io/swapday-privacy/
- 본문: index.html (한국어, 시행일 2026년 11월 12일), en/index.html (English)
- 앱 자체는 개인정보를 직접 수집하지 않음 (localStorage만 사용). 광고 제공을 위한 Google AdMob SDK 수집 내역은 방침에 명시.
