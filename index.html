1. 수집하는 정보

2. 데이터 저장 방식

사용자가 등록한 소모품 목록, 교체주기, 교체 이력은 사용자 기기 내부(localStorage)에만 저장되며, 외부 서버로 전송되지 않습니다.

3. JSON 내보내기·가져오기

JSON 내보내기로 저장한 파일은 사용자 기기의 다운로드 폴더에만 저장되며, 가져오기한 파일도 사용자 기기 내부에서만 처리됩니다. 파일이 외부 서버로 전송되지 않습니다.

4. 제3자 제공

본 앱 자체는 사용자의 정보를 제3자에게 제공하지 않습니다. 단, 광고 제공을 위해 Google AdMob SDK가 포함되어 있으며, AdMob SDK가 수집하는 정보는 제5절에 명시되어 있습니다.

5. 광고

본 앱에는 Google AdMob을 통한 광고(하단 배너)가 포함되어 있습니다. 광고 제공을 위해 AdMob SDK가 다음 정보를 수집할 수 있습니다.

  • 기기 또는 기타 ID (광고 ID)
  • IP 주소 (대략적인 위치 추정용)
  • 광고 상호작용 기록 (광고 클릭 등)
  • 진단 정보 (충돌 로그 등)

수집된 정보는 광고 제공·부정 방지를 위해 Google과 공유될 수 있습니다. 맞춤 광고를 원치 않으시면 기기 설정에서 '광고 개인 최적화'를 해제해 주세요.
